# Vape Hub

A static vape storefront demo built with HTML, CSS, JavaScript, and Bootstrap 5.

## Run locally

Open `vape.html` in a web browser. The page loads Bootstrap from a CDN, so an internet connection is needed for Bootstrap styles and components.

## Features

- Product showcase and image carousel
- Responsive navigation styled with Bootstrap
- Login/profile interface that stores the entered username in browser `localStorage`
- Local product and branding images

## Project files

- `vape.html` - storefront page
- `vape.css` - page styles
- `script.js` - login and profile interactions
- `img/` - carousel and product images

The login is a front-end demo only; it does not authenticate users with a server.
